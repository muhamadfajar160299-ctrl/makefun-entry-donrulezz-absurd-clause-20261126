Entry for [The Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1) on make.fun.

`main.py` deterministically writes one original English sentence — a single
absurd clause that could sit buried deep inside a terms-of-service
agreement — to `entry.txt` (at most 200 characters).

Run it with:

```sh
python3 main.py
```
